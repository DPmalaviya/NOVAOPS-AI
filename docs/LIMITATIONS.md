# Current limitations

At Stage 1, NovaOps has no document ingestion, vector index, query embedding, RAG chat, provider integration, GitHub synchronization, research workflow, persistent metrics, evaluation dataset, public deployment or production usage telemetry. The web UI intentionally labels these as unavailable rather than simulating them.

Published free tiers are allowances, not a guarantee of account activation, capacity or a hard no-cost cap. Gemini free-tier requests may be used to improve provider products, so NovaOps will only permit public or synthetic content in that path. Cloudflare Worker CPU constraints may require smaller uploads or a different proven processing architecture. Ollama Cloud is optional until its account-specific free entitlement is verified.
